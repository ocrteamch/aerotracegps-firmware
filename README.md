# AeroTraceGPS Firmware

Firmwares prêts à flasher pour le récepteur (RX) et les balises (TX) AeroTraceGPS.

La région radio n’est plus fixée à la compilation : un seul firmware par carte pour toutes les régions, plus besoin de reflasher une version différente.
La région se choisit directement depuis l’app AeroTraceGPS (iOS) en Bluetooth, sur le récepteur (RX) et sur chaque balise (TX), et elle est mémorisée dans la carte.
Régions disponibles : EU868 (866,5 MHz, valeur par défaut), US915 (915,0 MHz), AU915 (917,0 MHz), AS923 (923,2 MHz).

The radio region is no longer set at compile time: one firmware per board for all regions, no more flashing a different build
Pick the region directly from the AeroTraceGPS iOS app over Bluetooth, on the receiver (RX) and on each beacon (TX). It is stored on the board.
Available regions: EU868 (866.5 MHz, default), US915 (915.0 MHz), AU915 (917.0 MHz), AS923 (923.2 MHz).
